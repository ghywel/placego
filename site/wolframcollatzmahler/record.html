The record route, depth by depth

Pick a depth. The census holds the best configuration found for keeping the forced left row white starting there (the longest run where the value is exact), and the trace that forces it. The question the whole route turns on is whether that run is finite at every depth. The data say it grows; nobody can yet prove it never becomes infinite.

What is being asked

Suppose a finite pattern kept the centre alternating for ever. Its left side would be white beyond its support, an infinite run at some depth. So if the run is finite at every depth, no finite pattern can do it. The record is exact to depth 120 and at 132, 139 and 142, where it is 17 (how the record witness's run ends is explained at 132, and for one witness at 139), and also at 125 (21), 143 (17) and 147 (18); between and beyond, only bounds (the drawings above show the witnesses as exported on 11 October).
