The record route, depth by depth

Pick a depth. The census holds the configuration that keeps the forced left row white for the longest run starting there, and the trace that forces it. The question the whole route turns on is whether that run is finite at every depth. The data say it grows; nobody can yet prove it never becomes infinite.

What is being asked

Suppose a finite pattern kept the centre alternating for ever. Its left side would be white beyond its support, an infinite run at some depth. So if the run is finite at every depth, no finite pattern can do it. The record is exact to depth 120 and at 132, 139 and 142, where it is 17 and the mechanism that stops it is understood; between and beyond, only lower bounds. The statement in full.
