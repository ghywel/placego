The trove

Everything we computed, ready to pick up

Each entry is a file in the public repository, with what it holds, its format, the program that made it, its size and SHA-256, and where one exists a command that re-checks it from the file alone. Search by any word.

The catalogue is data/manifest.json, generated by build_manifest.py from a curated list; the files themselves are served from the repository. If a link fails, the file has moved: search the repository for its name.

Built in the open from the public record at github.com/ghywel/placego.
