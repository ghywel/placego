For every finite nonzero row $x$ of rule 30, read from its rightmost black cell $e$ (bit $k$ of the edge code is $x(e-k)$), the edge advances one cell per step and the code evolves by the 2-adic edge map $T$ of Coven, Pivato and Yassawi (`edge_evol`). We prove that the right edge of every such row is the single cell's ruler, cut off at one depth. Suppose the code agrees with the single cell's code at time $s_0$ on bits $0,\dots,k-1$, for some $k \ge 2$, while no code of the single cell's orbit agrees with it on bits $0,\dots,k$. Then at every time $t$ the code agrees with the single cell's code at time $s_0+t$ below bit $k$ and differs at bit $k$. Its white run behind the edge cell equals the single cell's when that run is shorter than $k-1$, is exactly $k-1$ when the single cell's is at least $k-1$, and is never longer (`frozen_ruler`). The single cell's code never has a white run of exactly $k-1$ (`no_width_at_depth`), so the cut width lies in a gap of the ruler. Every row has a depth, or agrees with the orbit at every depth (`depth_dichotomy`).

The kit's `Rule30RightPeriods` describes the single cell's right diagonals; this extends it to every finite row. The proof uses only the triangularity of $T$, with no counting of periods.

Not claimed: anything about the center column or the Prize problems, or that rows of infinite depth are the single cell's own rows (open).
