## Carrying review of L1309, with quantifiers made explicit

**PROVED, two-party carrying read:** Local's forward implication in §37.1 works
at a fixed period p, where every column is a p-bit cyclic word. If every state of
P forces its prescribed immediate predecessor whenever an upward history is long
enough, an infinite upward history matching P on two columns must agree with P
one column further up. Repeat at successive states. The available depth need not
be uniform initially; P has finitely many states, so a maximum exists if desired.

The black-edge history extends upward by white columns. It cannot equal a
nonwhite spatially periodic phase all the way up: arbitrarily long white prefixes
and spatial periodicity would make that phase white. This proves the desired
exclusion without assuming, without proof, that a non-rain phase cannot contain
a particular front word. Keep the ambient period p explicit: rigidity in H_p
need not survive lifting to H_(2p), where more histories are allowed.

**PROVED, carrying read:** top padding makes wall existence monotone over the
source-state set. A wall of D internal columns can be prefixed by the preceding
column of its source phase, producing D+1 internal columns. The two rain states
are closed under this operation. The full G8/G16 source sets used by T33 are too.
Thus UNSAT at D40 for every listed source state excludes all smaller nonnegative
D for those sources and the fixed target. Bottom padding alone generally changes
the fixed target state; it is unnecessary for this proof and should not be used
without a normalization argument. These are walls in the ambient p1024 graph,
not walls of arbitrary time period into a p1024 tail.

### Exact graph formulation of the converse (GPT PROOF-SKETCH)

**Status update, L1310:** Local has carried this finite-graph step; now PROVED
two-party. The historical heading is retained for existing links.

Let H_p have vertices (a,b), with edge (a,b)→(b,c) iff Delta(c)=a OR b.
For a chosen phase state v, let B(v) be its incoming neighbors other than the
predecessor prescribed by P. Let ReachCycle be the vertices reachable **from**
a directed cycle, allowing cycles of all periods dividing p in this same graph.
Then

`v is upward rigid at some finite depth  <=>  B(v) intersects ReachCycle trivially`.

Indeed, an arbitrarily long deviating history ends through some vertex of B(v).
There are finitely many vertices and finitely many choices in B(v). A sufficiently
long history repeats a vertex before that final predecessor, hence contains a
directed cycle with a path to B(v). Conversely, such a cycle can be traversed
arbitrarily many times before following the path and the last edge into v.
This is the finite-graph version of the existing GC2362 entrance/cycle reasoning;
no new general graph-theory claim is intended.

This formulation identifies what the word "wall" must include: an excursion
which leaves P and later returns to P counts, as does a path from a different
phase. Testing only walls between distinct named phases misses the first case.
Under this inclusive definition, rigidity of all non-rain/nonwhite phases is
equivalent to absence of a nontrivial cycle-origin entrance into those phases.
White has a unique predecessor (zero OR zero = zero), so it causes no exception.

**Scope repair:** this is the first, appropriately defined wall-destination clause
of Sink. It is not by itself equivalent to both clauses of the original §29.7
Sink definition, whose second clause already asserts the black-edge recurrence
conjecture. Rain-to-rain excursions still need their own exclusion. And a finite
graph's infinite walk need not eventually repeat; what finiteness provides is a
reachable cycle and a repeatable witness, sufficient for this reduction.
Local should carry this converse/formulation before we mark the iff PROVED.

### Use-case analysis while the benchmark runs

Primary source: Fleury and Biere, [Gimsatul,2022](https://arxiv.org/abs/2207.13577),
and upstream README/solve.c at the pinned4664fd74 commit. Read directly from the
retained clean source checkout. It is a portfolio solver with physically shared
immutable clauses and per-thread watches. Preprocessing is sequential; thread
strategies differ. Therefore increasing threads can change the amount of search,
not merely divide it. Proof production/checking remains a distinct workload; our
large LRAT check used a single checker plus decompression. No parallel-checker
speedup has been measured. The gzip chunks are storage units, not independent proof
subproblems: later LRAT lines can depend on earlier lines across a chunk boundary.
Checking those chunks independently would require a new sound proof decomposition.
Independent certified case splits are a different possible design; their coverage
and assembly would also need checking. Benchmark answers are compared to existing certificates;
timing runs themselves do not produce new proofs.

For a batch of independent finite questions, separate one-thread searches are a
plausible throughput option; they need a separate bounded scheduler and measurement,
not an inference from this single-instance comparison. For the front graph, regular
integer minimum-over-successors sweeps are a more natural GPU candidate than SAT's
branching and dynamic clause operations. A future implementation should group edges
by source and compute each source's minimum locally, use two value buffers, preserve
FAIL edges as an independent veto, and compare every sweep to a CPU oracle. Graph
construction, graph transfers and relaxation must be timed separately. No GPU speedup
or GPU-time/VRAM enforcement is claimed here; no GPU job was launched.

**A concrete reduction before hardware work (PROOF-SKETCH, self-check only):**
reuse the already known rotator symmetry (genealogy35.3; Cloud38.3 already suggests
collapsing alignments). This is an implementation application, not a claimed new
symmetry theorem. For the G16 ring y, c(y)_i = y_(i-72) modulo128. The state used by
front_cert.py is (R mod128,t mod16,w). Put phi = R-72t mod128. Its entire local
background at relative offset o is y_(phi+o), so the transition calculation depends
only on (phi,w). If its advance is a and its new window is w', the next state is
(phi+a-72 mod128,w'). The wrap at t=15 is consistent because16*72 is0 modulo128.

Each original state has exactly the same projected successors as every other state
with its (phi,w); the same unknown-bit choices also preserve FAIL and advance.
Thus every quotient path lifts from every compatible representative. Starting the
minimum-path recurrence at zero, induction keeps values constant on these fibres.
This would reduce the represented state count from2048*2^W to128*2^W, a factor16,
without strengthening the relaxation. It cannot remove a real FAIL/negative path
or repair the missing edge constraint. Do not mistake smaller graph size for a
proof that G16 is excluded, nor factor16 state reduction for measured16x speedup.
