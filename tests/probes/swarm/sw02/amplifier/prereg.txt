Question. AM-5 Candidate H: a one-sided block map on column words with A(N) in N and width cost w is 0 or F^j.
AM-5 s7: with T(x) = x xor (2x|4x), F(2x) = T(x), A(2^n y) = 2^(n-r) B_n(y), B_n = T^-(n-r) Psi T^(n-r), Psi(u) = A(2^r u),
B_n natural of width <= width y + c, c = r + w, periodic in n with 2-power period.

New step to test. If T acts transitively on a residue class, b_n = B_n(1) fixes Psi on the whole closure O_1 of the orbit of 1:
Psi(T^s 1) = T^s b_(r+s) for s in Z_2. So every natural y = T^s 1 in a piece must have T^s b natural, width <= width y + c.
This uses all naturals, not col(1), so it does not need col(1) to contain every word.

Predictions.
P1 (0.8). T has exactly two orbit closures on odd residues, {1,7 mod 8} and {3,5 mod 8}, and the orbit of 1 mod 2^k has size 2^(k-2) for k <= 28.
  Counterfactual: smaller orbits mean O_1 is thin, not clopen, and the reduction covers little.
P2 (0.85). For each natural b < 2^12 outside 0 and {T^j 1}, the pass set {natural y in O_1: T^s(y) b has zero bits above width y + c} misses every residue class of natural y mod 2^6, at c = 12.
  Counterfactual: a nontrivial b passing on a whole class is a candidate piecewise amplifier on deep rows. It would have to be tested against F-commutation.
P3 (0.6). log_1(y) is not an integer for natural y outside the orbit of 1, and no rational pattern shows at small y.
  Counterfactual: a rational pattern would give an explicit formula for T^s and a route to a hand proof.
