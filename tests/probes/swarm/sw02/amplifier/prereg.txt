AM-5 s7: with T(x) = x xor (2x|4x), F(2x) = T(x), A(2^n y) = 2^(n-r) B_n(y), B_n = T^-(n-r) Psi T^(n-r), Psi(u) = A(2^r u),
B_n natural of width <= width y + c, c = r + w, periodic in n with 2-power period.

New step to test. If T acts transitively on a residue class, b_n = B_n(1) fixes Psi on the whole closure O_1 of the orbit of 1:
Psi(T^s 1) = T^s b_(r+s) for s in Z_2. So every natural y = T^s 1 in a piece must have T^s b natural, width <= width y + c.
This uses all naturals, not col(1), so it does not need col(1) to contain every word.
